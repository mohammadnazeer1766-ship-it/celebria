# Cartoon Character Event Booking Website

A modern, responsive event booking website for live cartoon character bookings, built with React, Tailwind CSS, and Vite.

## Features
- **Responsive Design**: Works on mobile, tablet, and desktop.
- **Sticky Navbar**: With smooth scroll effects.
- **Hero Section**: Engaging banner with "Book Now" CTA.
- **Service Highlights**: Displaying key services.
- **Pricing Plans**: Detailed packages with hover effects.
- **Image Gallery**: Grid layout with lightbox popup.
- **Customer Reviews**: Testimonial cards.
- **FAQ Section**: Accordion style questions.
- **Mock Data**: Pre-populated with sample services and reviews.

## Tech Stack
- React (Vite)
- Tailwind CSS
- React Router DOM
- Lucide React (Icons)
- Framer Motion (Ready for animations)

## Getting Started

### Prerequisites
- Node.js installed

### Installation

1.  Clone the repository or navigate to the project folder.
2.  Install dependencies:
    ```bash
    npm install
    ```

### Running Locally

To start the development server:
```bash
npm run dev
```

Open `http://localhost:5173` in your browser.

### Building for Production

To create a production build:
```bash
npm run build
```

The output will be in the `dist` folder.
